# Brand sites

Four static demo websites for fictional brands (HTML, CSS and JavaScript, no
build step, no dependencies):

| Folder | Brand |
|---|---|
| `velora/` | VELORA Motors – automotive |
| `novae/` | NOVAÉ Skin – cosmetics |
| `nordfeld/` | NORDFELD – grocery retail |
| `arlowe/` | ARLOWE – fashion |

All brands, products, people and addresses are fictional. `index.html` lists
all pages.

## Run locally

```bash
python3 -m http.server 3003
```

Then open e.g. `http://localhost:3003/velora/`.
